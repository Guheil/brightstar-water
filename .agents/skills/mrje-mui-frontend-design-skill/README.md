# MRJE MUI Frontend Design Skill

This package is a reusable instruction set for an AI coding/design assistant working on the MRJE Gas and Bright Star frontend.

## Core behavior

The skill enforces:

- Material UI v9
- strict MUI `styled()`
- centralized global theme
- `theme.vars.palette.*` color usage
- separate `elements.tsx`
- no styling in `index.tsx` or `page.tsx`
- frontend-first prototype development
- Customer, Admin, and Deliverer roles
- anti-AI-slop design
- accessibility
- security-conscious frontend behavior
